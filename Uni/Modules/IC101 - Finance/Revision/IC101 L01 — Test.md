# IC101 L01 — Test

**После [[IC101 S01 — Practice|Seminar 1]]:** пройти тест без конспекта, сохранить ответы и разобрать результат.

## Открыть тест

**[[IC101 L01 — Revision Test.html|Открыть HTML-тест]]**

HTML-файл находится рядом с этой заметкой, в `Revision`. Открой его в **Google Chrome** через Finder → Open With → Google Chrome. Если Obsidian показывает код, открой файл через Finder, а не как текстовую заметку. Интернет и вход в Blackboard для этой локальной версии не нужны.

## Что внутри

| Часть | Количество | Проверка |
|---|---:|---|
| Вопросы сохранённого Blackboard Topic 1 | 15 MCQ | Автоматически, отдельный результат /15 |
| Дополнительные вопросы по твоим пробелам | 12 MCQ | Автоматически, отдельный результат /12 |
| Объяснения своими словами | 3 | Я проверю содержание по сохранённому файлу |

Дополнительные вопросы проверяют three pillars, DCF/NPV, required return и risk premium, P/E/EPS/dividends, P/B, bond coupon/yield, hedging, asset types, EMH, arbitrage и price/value.

Вопросы и варианты ответов первой части перенесены из [[small_test_L01.mhtml|сохранённого Blackboard Topic 1]]. Ключ самопроверки и пояснения подготовлены для этой локальной практики. Это не прошлый экзаменационный вариант и не отправка результатов в Blackboard.

## Как проходить

1. Закрой slides и cheat sheet. Калькулятор можно.
2. При желании нажми **«Начать»** у таймера. Жёсткого лимита времени нет; таймер можно поставить на паузу.
3. Выбери один вариант для каждого MCQ. Для расчётов и сложных вопросов добавляй ход решения или причину выбора. Можно писать по-русски с английскими терминами.
4. Заполни три письменных ответа. Английская орфография отдельно не подменяет проверку понимания.
5. Нажми **«Завершить и проверить»**. До этого правильные ответы скрыты.
6. Посмотри раздельные баллы и пояснения ошибок. За MCQ — 1 балл; пропуск — 0; штрафов в этой практике нет. Три письменных ответа автоматически не оцениваются.

Завершённая попытка остаётся в истории и доступна для просмотра. Для нового решения нажми **«Новая попытка»**. Включённые в HTML правила оценивания — правила этой практики; окончательные правила университетского экзамена проверяются отдельно.

## Как сохранять ответы

**В браузере:** ответы, пояснения, уверенность и история сохраняются автоматически. Продолжай с тем же HTML-файлом в том же браузере. После перезагрузки таймер на паузе. При ошибке сохранения тест покажет сообщение.

**В файле, доступном мне:**

- В Chrome нажми **«Связать JSON-файл»** и выбери **новый** файл с предложенным именем в папке `Revision/Attempts`. Пока страница открыта, ответы и результат будут записываться туда. Ориентируйся на сообщение **«Файл сохранён»**.
- После перезагрузки страницы или смены попытки связь с файлом нужно выбрать заново. Если продолжаешь ту же попытку, можно выбрать её прежний JSON; для новой попытки используй новое имя.
- В любом браузере можно нажать **«Скачать ответы · JSON»**. Если файл попал в Downloads, перемести его в `Uni/Modules/IC101 - Finance/Revision/Attempts`.
- **«Отчёт для Obsidian · MD»** создаёт читаемую заметку с вопросами, твоими ответами и результатом. Сохрани её в ту же папку; для восстановления попытки используй JSON.
- **«Восстановить из JSON»** возвращает ответы из файла. Существующие попытки в истории сохраняются.

Браузерное сохранение само по себе не создаёт файл в vault. До передачи мне результата обязательно сохрани JSON или MD в `Attempts`.

## Моя проверка

После сохранения напиши: **«Проверь мой результат L01, файл …»**.

Я прочитаю ответы из файла, проверю объяснения и расчёты, отделю предметные ошибки от языковых трудностей, предложу, что повторить, и обновлю [[IC101 — Revision Checklist]]. Я не вижу браузерный черновик напрямую и не проверяю его автоматически в фоне.

Сам по себе процент MCQ ещё не означает полного освоения L01. Учтём также самостоятельность объяснений, уверенность и повторную проверку на новых вопросах.
