# IC102 — Revision Checklist

Модуль: [[IC102]] · Порядок работы: [[Revision Pipeline]] · [[IC102 — Tutor Log|Даты и контекст]]

**На лекцию:** день 0 → проверка +1 → закрепление +3–4. Дни считаются от основного занятия. Все этапы пока не отмечены: новый revision ещё не выполнен.

Галочки показывают завершённые этапы; финальная означает самостоятельное решение ключевых новых задач после повторения. Свой cheat sheet создавай в этой папке по мере работы, например `IC102 L01 — Cheat Sheet.md`. Это памятка для учёбы; разрешённые материалы экзамена проверяем отдельно.

Лекций с материалами в vault пока нет. Когда они появятся, добавим здесь блоки по образцу восьми этапов из [[Revision Pipeline]].
