Пользователь сообщил, что именно B пока непонятен; точный этап затруднения ещё не установлен. Эти задачи остаются для пошагового разбора, затем нового самостоятельного решения.

### 2. Logarithm domains и самостоятельность

[[IC104 L01 — Exponentials and Logarithms Practice#Latest review — 3 November 2026, Questions 3–14|Проверка exp/log]].

- Явно проверять положительность каждого исходного log argument, ограничения square root и знаменателя.
- Не отбрасывать отрицательный x автоматически: положительным должен быть аргумент.
- Новые аналоги №12–13 решить без подсказки с domain и проверкой кандидатов; исходные верные корни с помощью не равны независимому освоению метода.
- №7: итог `3 < x < 8` верен, но строку `x > 8` заменить на `x < 8`; добавить `(3,8)`.
- №8: пока только сообщение о калькуляторе, без числовых ответов и степенных равенств. Оценить нельзя.

### 3. Небольшие исправления записи и объяснений

- Parabola №1: minimum при `a > 0`, не `a > 1`.
- Exp/log №1: объяснить значение ln своими словами и записать `y = ln(7)`; `ln(7) ≈ 1.95` до двух знаков.
- №4: `ln(a)+ln(b)=ln(a*b)`; умножаются аргументы внутри логарифма. Контрпример к сумме аргументов пока добавлен тьютором, не пользователем.
- №6: основание `a > 0`, `a != 1`; аргумент положителен.
- №9–10: точная и округлённая формы разделяются; для округления `≈`. `e^3 ≈ 20.09`, не 20.10 до двух знаков.

Эти замечания не равнозначны необходимости повторного изучения всех базовых тем.
